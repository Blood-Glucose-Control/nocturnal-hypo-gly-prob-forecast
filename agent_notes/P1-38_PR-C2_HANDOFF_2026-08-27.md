## Why modules can temporarily get longer in WS1

WS1 is first creating explicit helper seams and contract-preserving boundaries *inside* each family module so behavior remains stable while we untangle long methods.
That often increases local line count short-term (more named helpers, guard methods, and explicit normalization functions).

Net shrinking/consolidation happens after these seams are proven in multiple families, when shared patterns are moved to common surfaces and duplicated family-local code can be removed safely.
